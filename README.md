<h2 id="about">📖 About CampusOS</h2>

<p>

<h3>🖼️ Image Optimization</h3>

<p>CampusOS includes server-side image processing using <strong>PHP GD</strong>.</p>

<pre>
Upload Image
      ↓
Validate Image
      ↓
GD Processing
      ↓
Convert to WebP
      ↓
Optimize
      ↓
Store
</pre>

<p><strong>Benefits:</strong> smaller file size · reduced storage usage · faster page loading · lower bandwidth usage.</p>

<h2 id="installation">⚙️ Installation</h2>

<h4>1. Clone</h4>
<pre><code>git clone https://github.com/your-username/campusos.git
cd campusos</code></pre>

<h4>2. Install Dependencies</h4>
<pre><code>composer install</code></pre>

<h4>3. Create Environment File</h4>
<pre><code>cp .env.example .env</code></pre>
<p>Windows:</p>
<pre><code>copy .env.example .env</code></pre>

<h4>4. Generate Application Key</h4>
<pre><code>php artisan key:generate</code></pre>

<h4>5. Configure Database</h4>
<p>Edit <code>.env</code>:</p>
<pre><code>DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=campusos
DB_USERNAME=root
DB_PASSWORD=</code></pre>

<h4>6. Run Migrations</h4>
<pre><code>php artisan migrate</code></pre>
<p>Or with seed data:</p>
<pre><code>php artisan migrate --seed</code></pre>

<h4>7. Link Storage</h4>
<pre><code>php artisan storage:link</code></pre>

<h4>8. Run the Application</h4>
<pre><code>php artisan serve</code></pre>
<p>Open <a href="http://127.0.0.1:8000"><code>http://127.0.0.1:8000</code></a></p>

<h2 id="security">🔐 Security</h2>

<p>For production deployment:</p>

<ul>
  <li>Never commit <code>.env</code></li>
  <li>Never expose production passwords</li>
  <li>Use strong administrator credentials</li>
  <li>Enable HTTPS</li>
  <li>Use secure SMTP credentials</li>
  <li>Keep Laravel and PHP updated</li>
  <li>Restrict administrator access</li>
  <li>Replace public demo credentials before production use</li>
